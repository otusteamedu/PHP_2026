### Словарь данных

1. Блок инфраструктуры (описание объектов кинотеатра)

  1.1 Таблица cinemas (кинотеатры)
	- id: первичный ключ
	- name: название кинотеатра
	- city: город расположения кинотеатра
	- address: адрес кинотеатра

  1.2 Таблица halls (кинозалы)
	- id: первичный ключ
	- cinema_id: внешний ключ на cinemas
	- name: наименование зала

UNIQUE (cinema_id, name): гарантия того, что в одном кинотеатре не будет двух залов с одинаковым именем

2. Блок с местами в кинозале  (описание каждого кресла)

  2.1. Таблица seat_types (типы мест)
	- id: первичный ключ
	- type: описание типа кресла

  2.2. Таблица seats (места/кресла)
	- id: первичный ключ
	- hall_id: к какому залу относится данное кресло
	- seat_type_id: ссылка на тип (т.е. на таблицу seat_types)
	- row_code: обозначение ряда
	- seat_number: номер кресла в ряду
	- is_active: флаг доступности кресла (можно убрать из продажи в случае поломки)

UNIQUE (id, hall_id): Технический индекс для составных ключей в билетах.

3. Блок контента и расписания

  3.1. Таблица movies (фильмы)
	- id: первичный ключ
	- title: название
	- duration: длительность фильма (для проверки наложения сеансов)
    - release_date: время релиза в кинотеатре
	- age_rating: возрастной ценз

  3.2. Таблица screenings (сеансы)
	- id: первичный ключ
	- hall_id: в каком зале будет сеанс
	- movie_id: какой фильм будет показан
	- starts_at: время начала сеанса
	- ends_at: время окончания сеанса
	- status: состояние сеанса

С помощью GIST индекса на уровне БД запрещается записывать в один зал два фильма, которые пересекаются по времени

4. Блок с ценами сеанса

  4.1. Таблица screening_prices (цена сеанса)
	- screening_id: ссылка на сеанс
	- seat_type_id: тип места
	- price_amount: цена сеанса

5. Блок с заявками и клиентами

  5.1. Таблица customers (клиенты)
	- id: первичный ключ
	- email: электронный адрес
	- phone: телефон клиента

  5.2. Таблица orders (заказы, один заказ может содержать несколько билетов)
	- id: первичный ключ
	- customer_id: внешний ключ на таблицу клиенты	
	- status: reserved (бронь), paid (оплачено), cancelled (отменено)
	- created_at: время создания заказа
	- paid_at: время оплаты заказа

  5.3. Таблица tickets (билеты)
    - id: первичный ключ
	- order_id: к какому заказу относится билет
	- screening_id: на какой сеанс
	- seat_id: на какое конкретное место
	- hall_id: в каком зале
	- price_amount: цена билета на момент продажи

UNIQUE (screening_id, seat_id): защита от продажи места дважды

# Приложение верификации email

### Основная задача
1.1. Реализовать приложение (сервис/функцию) для верификации email.

1.2. Реализация будет в будущем встроена в более крупное решение.

1.3. Минимальный функционал - список строк, которые необходимо проверить на наличие валидных email.

1.4. Валидация по регулярным выражениям и проверке DNS mx записи, без полноценной отправки письма-подтверждения.

------------

### Результат

------------
**Выполнить в терминале следующие команды (под ОС windows)**
 - composer install
 - cp .env.example .env

**Запустить Docker, выполнив команду**

- dev сборка

```
docker compose -f docker-compose.prod.yaml -f docker-compose.dev.yaml up --build -d
```

- prod сборка

```
docker compose -f docker-compose.prod.yaml up --build -d
```

**Функциональность**

- добавить в поле до 10 адресов электронной почты
- нажать кнопку "Проверить сейчас" или дождаться автоматического отправления данных

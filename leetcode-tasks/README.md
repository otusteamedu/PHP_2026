# Решение задачи на слияние двух списков

**Обоснование сложности**

Решение имеет временную сложность O(n + m), так как я прохожу по каждому списку линейно один раз. 

Что касается памяти, то алгоритм слияния работает за O(1) дополнительной памяти, из-за переставления ссылки существующих узлов списка. 

Просто из-за конвертации массивов в списки сложность составляет O(n + m)

Конвертацию сделал для наглядности примера.

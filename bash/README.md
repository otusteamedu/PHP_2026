## Домашнее задание (bash)

1. Клонировать проект
2. Перейти в директорию bash
3. В консоли выполнить следующие команды:

* Собираем docker image

```
docker build --no-cache -t app .
```

* Запускаем bash скрипты

```
docker run --rm app
```

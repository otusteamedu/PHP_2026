# Консольное приложение поиска по книжному интернет-магазину с помощью Elasticsearch

### Основная задача
1. Реализовать поиск по книжному интернет-магазину с помощью Elasticsearch
2. Критерии:
    - у каждого товара есть название, категория, цена и кол-во остатков на складе
    - поиск должен корректно работать с опечатками и русской морфологией. Пример: пользователь ищет все исторические романы дешевле 2000 рублей (и в наличии) по поисковому запросу "рыцОри". В результате должны вернуться товары, ранжированные по релевантности
3. Приложение должно быть реализовано в виде консольного PHP-приложения, которое принимает один или несколько параметров командной строки и выводит результат в виде текстовой таблицы, после чего завершает работу
4. NDJSON приложен 

------------

### Результат

------------

**Краткое описание проекта и его особенностей**

1. Стэк

    - php 8.3 
    - Elasticsearch 9.3 (далее - ES)
    - symfony console (CLI)
    - docker

2. Архитектурные решения

    - моделирование данных. Используется класс app/Doman/Book, который гарантирует, что данные в индекс ES попадут в консистетном состоянии. Одновременно производится расчет общего остатка, что осуществляется на уровне класса до отправки в ES.
    - индексация и маппинг. При создании индекса используется явное определение маппинга в классе app/Infrastructure/BookIndexService. К примеру, поле categroy индексируется дважды как text (для поиска по частям) и как keyword (для точной фильтрации). Также подключены анализаторы для корректной обработки русского языка. 
    - исморт данных реализован в классе app/Infrastructure/BookImport через _bulk, что позволяет загружать большие объемы данных быстрее построчной вставки.

3. Поисковая логика

    - использовался подход в классе app/Infrastructure/BookSearch с multi_match и весовым коэффицентом, т.е. сопадение в заголовке книги (title^3) оценивается выше, чем в категории (category^1.5), что влияет на релевантность.
    - фильтры по цене и наличию книги в магазине работают в контексте фильтрации - для кэширования, ускоряя повторные запросы.
    - настроено автоматическое исправление опечаток ('fuzziness' => 'AUTO')

4. Надежность

    - в классе app/Infrastructure/BookImport при импорте файла NDJSON используется тип операции index, что обеспечивает идемпотентность, скрипт можно запускать повторно
    - обработка файлов в формате ТВОЫЩТ реализована через построчное чтение для предотвращения переполнения памяти

5. Вывод данных: используется пакет symfony/console

    - для импорта данных и создания индекса в ES в классе app/Command/ImportBooksCommand
    - для реализации поиска в классе app/Command/SearchBooksCommand. Используются следующие флаги:

    | Опция | ТИП | Описание |
    |-------|-----|----------|
    | --q | VALUE_OPTIONAL | Поисковая строка. Ключевое слово для полнотекстового поиска по полям title и category. Поддерживает нечеткое соответствие |
    | --category | VALUE_OPTIONAL | Фильтр по категории. Использует точное совпадение (term query) через поле category.keyword |
    | --max-price | VALUE_OPTIONAL | Фильтр по цене. Ограничивает выдачу книгами, цена которых меньше или равна указанной |
    | --in-stock | VALUE_NONE | Флаг наличия. При указании убирает товары с нулевым остатком |
    | --limit | VALUE_OPTIONAL | Пагинация. Ограничивает количество выводимых строк в таблице (по умолчанию — 10) |

#### Как запустить проект?

**Выполнить в терминале следующие команды (под ОС windows)**
 - клонировать проект из github репозитория и выполнить команду composer install
 - переименовать env файл: cp .env.example .env

**Запустить Docker, выполнив команду**

```
docker compose up --build -d
```

**Выполнить импорт данных**

```
docker compose exec app php bin/console books:import books.json
```

**Пример команд**

- поиск по названию

```
docker compose exec app php bin/console books:search -q "рыцОри"
```

- фильтр по категории и цене

```
docker compose exec app php bin/console books:search --category="Фантастика" --max-price=1500
```

- выбор только тех книг, что в наличии

```
docker compose exec app php bin/console books:search -q "терминатор" --in-stock
```

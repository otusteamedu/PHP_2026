# AErmolenko/hw13 - Решения алгоритмических задач, через хеши

- В корне 5 php файлов с решениями 5 задач с Leetcode.
- В phpdoc класса Solution указано описание задачи с примерами.
- В phpdoc функции указано описание сложности.


Задачи на LeetCode:


- Задача: https://leetcode.com/problems/two-sum/description/
- Сложность: Время: O(n) - один проход по массиву


- Задача: https://leetcode.com/problems/sort-array-by-increasing-frequency/description/
- Сложность: O(n log n) - подсчёт частот O(n), сортировка O(n log n)


- Задача: https://leetcode.com/problems/intersection-of-two-arrays/description/
- Сложность: O(n + m) - по одному проходу по каждому массиву


- Задача: https://leetcode.com/problems/largest-positive-integer-that-exists-with-its-negative/description/
- Сложность: O(n) - два прохода по массиву


- Задача: https://leetcode.com/problems/how-many-numbers-are-smaller-than-the-current-number/description/
- Сложность: O(n + k log k), где k — количество уникальных значений

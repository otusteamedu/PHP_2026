# Задание 4: IS/hw4

## Общее описание

Это отчёт по выполнению задания 4 курса *Otus PHP Professional Developer*. В рамках задания развёрнута инфраструктура с балансировкой нагрузки и реализована валидация строки с круглыми скобками.

## Инфраструктура

### Схема развёртывания

Развёрнута следующая инфраструктура:

1. **Виртуальная машина**  
   - ОС: Ubuntu  
   - Среда: Oracle VirtualBox

2. **Nginx (первый уровень)**  
   - Выполняет балансировку нагрузки на два Nginx второго порядка.

3. **Nginx (второй порядок, 2 экземпляра)**  
   - Каждый балансирует нагрузку на два контейнера с `php-fpm` перекрестно.

4. **Контейнеры с `php-fpm`**  
   - Имеют доступ к общей папке с проектом на локальной машине (через монтирование).
   - Обращаются к контейнеру с **Redis** для хранения сессий.

5. **Контейнер с Redis**  
   - Используется для хранения сессий PHP.

## Реализация валидации строки

### Файл: `string_validation.php`

Скрипт выполняет валидацию строки, содержащей только круглые скобки `()`.

### Логика валидации

1. **Проверка наличия параметра**  
   - Убеждается, что в запросе присутствует параметр `string`.

2. **Проверка на пустоту**  
   - Если строка пуста, возвращается ошибка.

3. **Проверка на посторонние символы**  
   - Допускаются только символы `(` и `)`.  
   - Любые другие символы приводят к ошибке.

4. **Баланс скобок**  
   - В процессе прохода по строке:  
     - Если количество закрытых скобок `)` превышает количество открытых `(`, строка считается некорректной.  
     - В конце строки количество открытых и закрытых скобок должно быть равно.

5. **Итоговый результат**  
   - Если все проверки пройдены, строка считается корректной.  
   - В случае ошибки возвращается описание проблемы.

### Примеры корректных строк

- `()`
- `(())`
- `()()`

### Примеры некорректных строк

- `)(` (закрывающая скобка в начале)
- `(()` (нехватка закрывающей скобки)
- `(a)` (посторонний символ)
- `` (пустая строка)

6. **Код HTTP**
- `200` - OK (успешная валидация)
- `400` - Bad Request (не успешная валидация)
- `422` - Unprocessable Entity (параметр string не передан)

## Как запустить

1. Убедитесь, что инфраструктура развёрнута (см. раздел *Инфраструктура*).
2. Отправьте HTTP‑запрос с параметром `string`, например:
```
curl --request POST \
  --url http://localhost:80/string_validation.php \
  --header 'Content-Type: multipart/form-data' \
  --form 'string=()()()()()(())'
```

## Домашнее задание №12: Паттерны работы с данными

### Реализовано:
- **DataMapper**: Классы `UserMapper` и `PostMapper` полностью инкапсулируют логику работы с БД (Percona 8.4).
- **Identity Map**: Реализовано кэширование объектов в памяти внутри маппера для предотвращения дубликатов и лишних SQL-запросов.
- **Lazy Load**: Отложенная загрузка связанных сущностей (посты пользователя) выполняется только при вызове соответствующего метода.
- **Collection**: Реализовано массовое извлечение данных через метод `findAll()`.

### Инфраструктура:
- Использован современный стек: **PHP 8.4.18**, **Percona 8.4**, **Angie 1.11.4**.
- Настройка сети: **Zero-Trust** (БД закрыта внутри docker-сети, доступ к внешнему миру только у веб-сервера).
- Безопасность: Конфиденциальные данные вынесены в `.env` (в репозитории только `.env.example`).

### Как проверить:
1. Выполнить `cp .env.example .env`.
2. Запустить `docker compose up -d`.
3. Схема и тестовые данные загружаются автоматически из `init.sql`.

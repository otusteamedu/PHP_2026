# Проектирование БД кинотеатра

1. В файле cinema.sql скрипты для создания и заполнения базы. В этом же файле внизу запрос для поиска самого прибыльного фильма.
2. В файле ER_MODEL.md описана ER модель
3. В Makefile описаны команды, чтобы запустить и удалить docker контейнер с бд mysql

В таблице prices описаны базовые цены, которые зависят от фильма и типа места.
Подразумевается, что итоговая цена при покупке билета формируется по большему количеству параметров (время сеанса, промокод, льготный билет и т.п.).
В таблице tickets в поле price фиксируется фактическая цена покупки.

# AErmolenko/hw19 - Работа с очередью

Веб-приложение обработки **отложенных запросов** на примере генерации
банковской выписки. Пользователь отправляет форму, запрос мгновенно
ставится в очередь **Apache Kafka**, а фоновый воркер обрабатывает его и
сохраняет готовую выписку письмом в виде `.eml`-файла.

## Архитектура

nginx - Веб-сервер, отдаёт форму и принимает POST

php - PHP-FPM приложение (producer - кладёт запрос в Kafka)

worker - CLI-скрипт `bin/consumer.php` (consumer)

kafka - Брокер очереди (Apache Kafka, режим KRaft)

## Запуск

```bash
cp .env.example .env
docker compose up --build -d
docker compose exec php composer install
```

## Как пользоваться

1. Откройте http://localhost:8080/ и заполните форму:
2. После отправки увидите страницу `Запрос принят в обработку` с идентификатором запроса.
3. Воркер заберёт сообщение из очереди, «сформирует» выписку:
   - выведет результат в консоль;
   - сохранит письмо `.eml`-файлом в каталог `var/mail/`.

```bash
docker compose logs -f worker
```

Письмо с готовой выпиской появится файлом `var/mail/<id>.eml` - его
можно открыть любым почтовым клиентом или текстовым редактором.

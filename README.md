## Bash-скрипты — основы

Набор утилит/скриптов на Bash для выполнения заданий по работе с числами и текстовыми таблицами.

## Цель
Написать корректные и понятные shell-скрипты, демонстрирующие проверку аргументов, арифметику с числами (включая дробные) и обработку табличных текстовых данных стандартными утилитами Linux.

### Описание проекта
Набор небольших учебных Bash-скриптов, каждый из которых решает конкретную задачу:
- арифметические операции над двумя аргументами с проверкой входных данных;
- обработка текстовой таблицы пользователей (фильтрация, агрегирование, поиск популярных значений);

Скрипты сделаны так, чтобы их было просто читать, тестировать и запускать в среде Linux или в Docker-контейнере.

## Структура проекта
- `calc_awk.sh` — скрипт для суммирования чисел с использованием `awk` (пример обработки и проверки аргументов).
- `calc_bc.sh` — скрипт для суммирования чисел с использованием `bc` (поддержка дробных чисел).
- `readme.md` — этот файл с описанием и примерами использования.

## Особенности
- Валидация аргументов (проверка, что переданы числа).
- Поддержка целых и дробных чисел (в зависимости от скрипта).
- Примеры использования команд `awk`, `uniq`, `sort`, `head` для анализа табличных данных.

## Требования
- POSIX-совместимый shell (bash предпочтительнее).
- Утилиты: `awk`, `sort`, `uniq`, `head`, `bc` (для `calc_bc.sh`).

## Установка
Проект не требует сборки. Достаточно иметь доступ к Bash и перечисленным утилитам. В среде Debian/Ubuntu можно установить `bc` командой:

```bash
sudo apt update && sudo apt install -y bc
```

Если вы запускаете внутри Docker на Windows, учтите возможные отличия поведения утилит (например, `sort`).

## Использование

1) Пример: суммирование двух чисел

```bash
./calc_awk.sh 1.5 -7
# или
./calc_bc.sh 1.5 -7
```

Ожидается вывод в stdout с суммой значений или сообщение об ошибке при неверных аргументах.

2) Пример: три самых популярных города в табличном файле

Файл с данными по умолчанию: `city_table.txt` (формат: `id user city phone`). Команда для вывода топ-3 городов:

```bash
./sort_table_from_file.sh city_table.txt
```

Результат будет строками вида: количество_записей город, например `3 Moscow`.

## Примеры вывода
- `./calc_awk.sh 1.5 -7` → `-5.5`
- `./calc_bc.sh 2.25 3.75` → `6.00` (в `bc` формат может зависеть от скрипта)
- Команда для топ-3 городов над `city_table.txt` (после добавления тестовых данных) может вывести:

```
 3 Moscow
 2 Saint-P
 1 Kazan
```

Эта команда выводит три города с наибольшим числом записей.

## Тестирование
- Проверяйте скрипты на граничных значениях и при отсутствии аргументов.
- Для `calc_bc.sh` убедитесь, что установлен `bc`.

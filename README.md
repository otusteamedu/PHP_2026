# Задание 5: IS/hw7

## Общее описание

```
Слияние двух отсортированных списков
```
[https://leetcode.com](https://leetcode.com/problems/merge-two-sorted-lists/description/ "Ссылка на задачу")

## Примеры
```
Example 1
List 1: [1, 2, 3, 4, 4]
List 2: [1, 1, 2, 3, 4, 4]
Merge list: [1, 1, 2, 3, 4, 4]

Example 2
List 1: []
List 2: []
Merge list: []

Example 3
List 1: []
List 2: [0]
Merge list: [0]
```

## Запуск

```php
php MergeTwoSortedLists.php
```

## Сложность

```
Сложнось O(n) - линейная, т.к зависит напрямю от кол-ва переданных данных.
```

# Поиск по книжному магазину (Elasticsearch)

Консольное PHP-приложение для полнотекстового поиска с поддержкой русской морфологии и обработки опечаток.

## Функционал
- Поиск с учетом словоформ русского языка.
- Устойчивость к опечаткам (Fuzziness).
- Фильтрация по цене и наличию на складе.
- Форматированный табличный вывод результатов.

## Требования
- Docker / Docker Compose

## Инструкция по запуску

1. Разверните инфраструктуру:
   ```bash
   docker compose up -d
   ```

2. Инициализируйте индекс и загрузите данные (выполняется один раз):
   ```bash
   docker exec -it evgeny87-php php /var/www/html/index.php
   ```
3. Выполните поиск (пример запроса с опечаткой):
   ```bash
   docker exec -it evgeny87-php php /var/www/html/index.php "рыцОри" 2000
   ```
   Где "рыцОри" — поисковый запрос, а 2000 — максимальная цена.

## Структура проекта

- src/index.php — основная логика приложения.
- src/books.json — исходные данные товаров.
- docker-compose.yml — описание стека сервисов.

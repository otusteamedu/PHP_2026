# AErmolenko/hw7

## Задача

Merge Two Sorted Lists — слияние двух отсортированных связных списков в один отсортированный список.

## Запуск

```bash
docker compose build
docker compose up -d
```

Войти в оболочку контейнера:
```bash
docker exec -it php bash
```
и выполнить 
```bash
composer i
php src/index.php
```

## Обоснование сложности
### Временна́я сложность: O(n + m)

`n` и `m` — длины `list1` и `list2` соответственно.

На каждой итерации цикла `while` один из указателей продвигается на один узел вперёд. Цикл завершается, когда один из списков исчерпан, после чего оставшийся хвост подключается за O(1). Каждый из `n + m` узлов посещается ровно один раз.

## Исключительные случаи

| Вход                  | Результат       |
|-----------------------|-----------------|
| `[1,2,4]` + `[1,3,4]` | `[1,1,2,3,4,4]` |
| `[]` + `[]`           | `[]`            |
| `[]` + `[1,3,4]`      | `[1,3,4]`       |
| `[1,2,4]` + `[]`      | `[1,2,4]`       |
| `[2]` + `[1]`         | `[1,2]`         |
| `[1,5]` + `[2,3,4,6]` | `[1,2,3,4,5,6]` |

# PHP_2026

**Docker**
1. Установить Docker себе на локальную машину
2. Описать инфраструктуру в Docker-compose, которая включает в себя
	1. nginx (обрабатывает статику, пробрасывает выполнение скриптов в fpm)
	2. php-fpm (соединяется с nginx через tcp-порт)
	3. redis (соединяется с php по порту)
	4. memcached (соединяется с php по порту)
	5. БД соединяется по порту (не забудьте про директории с данными)
3. 1.3 (Со звездочкой) Можно установить Composer
4. 1.4 (Со звездочкой) Соединить FPM и Nginx через unix-сокет

Запуск окружения (пример):

1. Собрать и запустить сервисы:

```bash
docker-compose up -d --build
```

2. Откройте http://localhost:8080 — должен отображаться `src/index.php`.

Данные базы и Redis сохраняются в локальной папке `./data`:

- MySQL: `./data/db`
- Redis: `./data/redis`

Пояснения по конфигурации:

- `nginx` — отдаёт статику и проксирует PHP на `php:9000` (TCP).
- `php` — образ собирается из `php/Dockerfile`, подключается к Redis и Memcached по хостнеймам `redis`/`memcached`.
- `redis`/`memcached` — открыты на стандартных портах `6379` и `11211`.
- `db` — MySQL доступна на порту `3306`.
